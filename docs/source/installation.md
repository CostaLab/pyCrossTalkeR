# Installation

You can install pyCrossTalkeR with the simple commands below:

```
pip install pycrosstallker
```



***Note:** Please avoid to use the following characters in celltype name: '$'*

## Possible system dependencies

```
libudunits2-dev
libgdal-dev
gdal-bin
libproj-dev
proj-data
proj-bin
libgeos-dev
```
